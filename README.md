# JavaScript

This is my JavaScript workspace — where I learn by rebuilding, not just by completing.

Most of what's here started from a prompt (a course exercise, a lab requirement) — but the requirement is the floor, not the ceiling. Once a solution passes, the real work starts: rebuilding it a second way, comparing what changes, and writing down why one approach holds up better than another. That process — not the original prompt — is what most of this repo actually contains.

## Why this is worth a look

If you're expecting a folder of copy-pasted exercise answers, you won't find that here. Every lab that could reasonably be solved more than one way *was* solved more than one way — different built-in methods, different data structures, different ways of organizing state — each with a README explaining the trade-off, not just the code. That comparison work is the part a finished-answer search engine can't hand you.

## Structure

```
javascript/
├── freecodecamp/       — algorithm exercises, each rebuilt and compared beyond the original ask
│   └── basic-algorithm-scripting/
└── projects/            — original, self-directed projects
```

## `freecodecamp/`

Don't let the name undersell it — see [`freecodecamp/README.md`](./freecodecamp/README.md) for what actually happens in there: multiple implementations per lab, deliberate design decisions (mutating vs. non-mutating methods, `switch` vs. data-driven lookups, global state vs. encapsulated state), and the reasoning behind each choice, written out.

## `projects/`

Original, self-directed work — no course, no test suite handed to me. Reserved for what comes after the fundamentals.
